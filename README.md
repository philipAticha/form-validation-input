
   Form Validation Input

A  web application that validates user input before form submission using HTML, CSS, and JavaScript.

   Features

* Clean and responsive form interface
* Required field validation
* Email format validation
* Password and confirm-password matching
* Inline error messages
* Prevention of invalid form submissions

   Technologies Used

* **HTML5**
* **CSS3**
* **JavaScript**

   Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/philipAticha/form-validation-input.git
   ```

2. Navigate to the project folder:

   ```bash
   cd form-validation-input
   ```

3. Open `index.html` in your web browser.

   Usage

Enter the required information into the form and submit it. The application checks the entered values and displays appropriate error messages when the input is invalid.
